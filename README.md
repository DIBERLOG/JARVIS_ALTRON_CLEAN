# JARVIS ALTRON CLEAN

### Не просто «открой браузер». Личный центр, который умеет слушать.

**Версия 0.4.0 · Windows · Rust + Tauri + Svelte**

Представь: ты садишься за компьютер, а JARVIS уже готов помочь. Можно попросить открыть Telegram, узнать погоду, перейти в разговорный режим или быстро превратить мысль в текст. А когда хочется не разговаривать, а разобраться с делами — рядом календарь, заметки, привычки, тренировки и история запросов.

Это не обещание универсального искусственного интеллекта. Это развивающийся настольный помощник: понятные команды, локальные инструменты, две личности и интерфейс в тёмных бирюзовых цветах.

> «Джарвис, давай пообщаемся».
>
> Или просто открой «Центр» — всё важное рядом.

## За минуту: что здесь интересного

- **Управление голосом.** Приложения, сайты, погода, счётчик и повтор последней команды.
- **Две личности.** Спокойный JARVIS или прямой ALTRON — с общими возможностями, но разной манерой ответа.
- **Диалог и свежая информация.** Локальная Ollama либо DeepSeek, веб-поиск с источниками.
- **Личный центр.** От новостей и заметок до тренировок и зашифрованных карточек паролей.
- **Голос в текст.** Запись с микрофона или короткий аудиофайл, волны голоса и автоматическая пунктуация.
- **Реальная статистика.** Привычки, тренировки и запросы считаются по твоим записям, а не по демонстрационным цифрам.
- **Контроль слушания.** Пауза микрофона кнопкой или глобальной комбинацией клавиш.

Подробности последнего обновления: [UPDATES-0.4.0.md](UPDATES-0.4.0.md).

## Первое знакомство

У JARVIS два основных процесса:

| Процесс | Что делает |
| --- | --- |
| `jarvis-app.exe` | Голосовой движок: слушает, распознаёт речь, выполняет команды и ведёт голосовой разговор |
| `jarvis-gui.exe` | Интерфейс: настройки, чат, «Центр», карточки и диаграммы |

Для голосовых команд нужен работающий движок. Отсутствие связи с ним не означает, что перестали работать заметки или остальные локальные разделы.

В верхней панели доступны **Центр**, **Команды**, **Чат** и **Настройки**. Окно появляется с плавной анимацией снизу.

Для знакомства:

1. Проверь выбранный микрофон и модель распознавания в настройках.
2. Открой «Команды» и посмотри доступные фразы.
3. Попробуй простую команду открытия приложения.
4. Зайди в «Центр → Голос в текст» и запиши короткую фразу.
5. Создай заметку, привычку или таймер на своё время.

Приветствие зависит от времени суток на компьютере. Если системный часовой пояс — Москва, используется московское время; отдельного обязательного привязывания к МСК нет.

## Голосовые команды и разговор

### Обычные команды

Раздел «Команды» поддерживает представление **списком**, **плитками** и **по категориям**. Метка **33+** обозначает расширенный набор команд; фактический список и варианты фраз смотри в интерфейсе.

| Что попросить | Примеры |
| --- | --- |
| Браузер и сайты | «открой браузер», «открой гугл», «открой ютуб», «открой чат гпт» |
| Приложения | «открой дискорд», «открой стим», «открой телеграм» |
| Работа и учёба | «открой вс код», «открой расписание», «открой калькулятор» |
| Режимы | «игровой режим», «рабочий режим» |
| Погода | «какая погода», «погода в Москве», «установи город Казань» |
| Счётчик | Прибавить или убрать единицу |
| Повтор | Повторить последнюю команду |
| Ответы ассистента | «спасибо», «как дела», «расскажи анекдот» |

Фразы в таблице — примеры, а не замена словарю команд. Некоторые сценарии используют установленное приложение, системные пути, браузер или интернет. На другом компьютере их может потребоваться настроить.

### Разговорный режим

Чтобы начать:

> «Джарвис, давай пообщаемся».

После входа можно говорить последующие реплики без постоянного повторения имени ассистента. Распознанный запрос передаётся выбранной модели, ответ озвучивается.

Внутри разговора обычные команды продолжают обрабатываться: просьба открыть приложение должна выполнять действие, а не превращаться только в обсуждение.

Чтобы выйти:

- «хватит общаться»;
- «закрой диалог»;
- «режим команд».

Голосовой разговор пока не следует воспринимать как долговременную память обо всех предыдущих беседах.

### Слушать или не слушать

Кнопка слушания управляет глобальным приёмом голосовых команд, а не только чатом. Комбинация по умолчанию — **Ctrl+Alt+J**; её можно изменить в настройках.

Пауза слушания не равна остановке озвучивания. Для речи ответа в чате есть отдельная компактная кнопка **«Остановить звук»**.

## Чат, личности и интернет

### Выбор модели

| Источник | Особенности |
| --- | --- |
| Ollama | Локальная модель; API-ключ не нужен. В конфигурации чата используется `qwen3:8b` по умолчанию |
| DeepSeek API | Требует личный ключ и интернет; сообщения отправляются внешнему сервису |

Модель и голосовые ответы выбираются в интерфейсе. Ключ DeepSeek не включён в репозиторий.

### JARVIS и ALTRON

- **JARVIS** — спокойный, практичный собеседник.
- **ALTRON** — более холодный и прямой стиль.

Выбор личности меняет манеру ответа, а не достоверность модели и не её возможности. Обе могут ошибаться. Настройки характера текстового чата и голосового диалога могут быть отдельными — проверь нужный раздел и сохрани изменения.

### WEB INTEL

Для новостей и актуальных вопросов предусмотрен автоматический поиск; переключатель WEB INTEL позволяет использовать его и для других запросов.

Модель получает найденные материалы, ссылки и доступные даты публикаций. Это не неограниченный доступ ко всем сайтам и не гарантия проверки каждого факта.

Поиск, погодный сервис и новостные источники зависят от внешних сайтов. Если они недоступны, приложение должно показывать ошибку, а не выдавать отсутствие результатов за подтверждённый факт. Важные сведения проверяй по открываемым источникам.

## Центр: все разделы

Меню «Центра» устроено как выбираемый список, без нумерации.

### Новости

Не только заголовки: карточки показывают источник, дату, краткое описание и иллюстрацию, если их передала лента.

Доступные темы:

**Главное, нейросети, политика, геймдев, игры, спорт, туризм и путешествия, технологии, наука, кино и сериалы, экономика, космос, кибербезопасность.**

Регионы: **Россия, США, Великобритания, Германия и Франция**. Набор доступных источников зависит от региона. Среди вариантов — Интерфакс, РБК, Лента.ру, ТАСС, Хабр, DTF, AP, CNN, BBC, The Guardian, Reuters, DW и другие.

Виды отображения:

- **Лента** — крупные последовательные публикации.
- **Плитки** — обзор сразу нескольких карточек.
- **Компактно** — более плотный список.

Есть обновление, индикатор загрузки, подгрузка следующих публикаций и переход к оригиналу. Не все источники передают обложку или описание: вместо отсутствующей фотографии показывается подписанная обложка темы, а не поддельный снимок статьи.

**Перевод на русский** выполняется локально через Ollama и `qwen3:4b-instruct`. Перевод заголовка и описания заменяет текст карточки; можно вернуть оригинал. Это не автоматический перевод всей страницы по ссылке.

### Календарь, напоминания и дни рождения

- Месячный календарь с переключением месяцев и выбором дня.
- Отметки напоминаний и дней рождения.
- Список событий выбранного дня.
- Создание напоминаний с датой и временем, отметка выполнения и удаление.
- Дни рождения с ближайшей датой и возрастом, если указан год.

Напоминания обслуживаются работающим приложением. Это не системный планировщик, который гарантированно разбудит выключенный компьютер.

### Заметки

Обычные заметки и чек-листы сохраняются отдельно от секретного хранилища.

В обычной заметке доступны:

- жирный, курсив, подчёркивание и зачёркивание;
- заголовки, размер и цвет текста;
- выделение маркером;
- маркированные и нумерованные списки;
- цитаты, код и разделители;
- выравнивание и ссылки;
- отмена и повтор действия;
- картинки через кнопку, перетаскивание или **Ctrl+V**.

Оформление видно сразу, а не только в отдельном предпросмотре. Картинки ограничены по размеру и подготавливаются перед сохранением; на HTML-содержимое заметки установлен лимит 8 МБ.

Чек-листы используют отдельные пункты с отметками выполнения. Переключение из богатого текста в чек-лист не сохраняет картинки и все стили.

Обычные заметки **не являются зашифрованным сейфом**. Пароли и секретные записи лучше хранить в разделе «Пароли».

### Голос в текст

Отдельная диктовка: произнесённое здесь не должно запускать голосовые команды.

Порядок работы:

1. Выбери микрофон.
2. Нажми «Начать запись».
3. Говори — волны реагируют на поступающий звук.
4. Нажми «Остановить и распознать».
5. Отредактируй результат, скопируй его или сохрани в заметки.

Поддерживаются запись до **2 минут** и загрузка аудиофайла до **10 МБ**. Чтение конкретного формата зависит от аудиодекодера среды приложения; при проблемах попробуй WAV, MP3 или M4A.

Распознавание выполняет локальная Vosk. Язык зависит от выбранной модели. Во время записи слушание команд временно приостанавливается, а затем возвращается к прежнему состоянию.

Новые результаты добавляются к имеющемуся тексту. Черновик остаётся при переключении разделов, но **не гарантируется после закрытия или перезапуска приложения**. Аудио диктовки не сохраняется на диск этим модулем.

#### Автопунктуация

Переключатель **«Автопунктуация»** включает запятые, точки, вопросительные знаки и заглавные буквы после распознавания.

- Обработка локальная, через `qwen3:4b-instruct`.
- Выбор переключателя запоминается.
- Кнопка **«Оформить текущий текст»** обрабатывает уже имеющийся результат.
- При недоступности обработки исходный текст остаётся.
- Результат проверяется на изменение слов: это оформление, а не свободное переписывание диктовки.

Пунктуация модели может быть неточной. Просмотри результат перед сохранением.

### Таймер

Круговой индикатор показывает оставшееся время и прогресс. Есть старт, пауза, продолжение, сброс и сигнал завершения.

Готовые интервалы: 5, 10, 15 и 30 минут, час и два часа; тематические пресеты — учёба, работа, перерыв, игры, тренировка и сон.

Можно:

- добавить свой именованный пресет;
- нажать **«Своё время»** и задать часы, минуты и секунды без сохранения пресета;
- выбрать интервал от **1 секунды до 23:59:59**;
- перейти в другой раздел, не прекращая отсчёт.

После установки своего времени нажми «Старт». Таймер хранит состояние и восстанавливает отсчёт при следующем запуске. Если приложение закрыто, оно не проиграет сигнал точно в момент завершения: просроченный отсчёт проверится после открытия.

### Погода на неделю

Прогноз на **7 дней**: погодные иконки, даты, график температуры и доступные показатели прогноза. Краткие рекомендации по одежде находятся на погодной карточке; отдельного пункта «Что надеть» в меню нет.

Команда установки города связана с погодой «Центра». Данные приходят от внешнего сервиса, а не генерируются моделью. Неудачная загрузка не означает, что на компьютере обязательно пропал интернет: сервис тоже может быть недоступен.

Рекомендации по одежде приблизительные — учитывай реальную погоду, длительность прогулки и личный комфорт.

### Привычки

Стартовый набор: зал, зарядка, завтрак, вода, прогулка, чтение и сон вовремя. Можно вести пользовательские привычки, отмечать выполнение и количественный прогресс.

Статистика собирается по сохранённым отметкам. Диаграммы показывают выполнение и динамику; пропущенные дни не заменяются красивыми случайными значениями.

### Тренировки и зарядка

Разделы тренировочного модуля:

**Сегодня → Зарядка → Мои параметры → Программы → Упражнения → История → Статистика → Рекорды.**

Возможности:

- Библиотека упражнений и программы PUSH, PULL, LEGS, FULL BODY.
- Ведение подходов: вес, повторения, субъективная сложность RPE и разминка.
- Предыдущие результаты, отдых, состояние и завершение тренировки.
- Карта тела спереди, сзади и в общем виде; выбор мышечной группы и скрытие карты.
- Параметры: рост, измерения веса, процент жира и способ его оценки, опыт, предпочтения и ограничения.
- Настраиваемая зарядка с отметками по дням.
- Семь уровней: от очень лёгкого до продвинутого.
- Подбор варианта на сегодня и ограниченный рандомизатор с учётом недавней нагрузки и самочувствия.
- Статистика рабочего объёма, веса тела, мышечных групп, настроения и рекордов.

Рандомизатор не должен предлагать бесконечную цепочку интенсивных тренировок. При боли или высокой усталости подбор может предложить отдых.

**Важно:** это дневник и вспомогательные правила подбора, не медицинская диагностика и не персональный тренер. Рост, вес и процент жира не назначают безопасный рабочий вес. Рабочие веса задаются пользователем; оценка 1RM не является подтверждённым максимумом. Карта тела отображает записи по группам, а не измеряет развитие мышц.

### История запросов

Находится в самом низу меню «Центра».

Категории: **Все запросы**, **История чата**, **Голосовые команды**. Есть поиск, даты и время, просмотр следующих записей и очистка с подтверждением.

История сохраняет до **500 новых запросов локально**. Старые запросы, сделанные до появления функции, автоматически не восстановятся.

Четыре вида статистики:

| Диаграмма | Что считает |
| --- | --- |
| Круговая | Записи чата и голосовой речи в выбранной выборке |
| Столбцы за 14 дней | Количество сохранённых запросов по дням |
| Тепловая карта часов | Распределение запросов по времени суток |
| Топ-5 | Повторяющиеся фразы с количеством повторений |

Категория и поиск влияют на диаграммы. Время отображается по настройкам компьютера.

Голосовая категория включает распознанные разговорные фразы; это **не** количество успешно выполненных команд. История не является полным архивом ответов модели.

Кнопки «Скрыть терминал» и «Открыть терминал» управляют доступным окном консоли без остановки ассистента. В окружениях без обычного окна консоли управление может быть недоступно.

## Хранилище паролей и восстановление

### Что хранится

Раздел «Пароли» — отдельные карточки с названием, логином, сайтом, скрываемым паролем, форматированным текстом и картинками.

По виду это близко к заметкам, но данные не добавляются к обычным заметкам или истории запросов и не отправляются в нейросеть этим модулем.

### Создание

1. Открой «Центр → Пароли».
2. Введи мастер-пароль и повтори его.
3. Сохрани показанный ключ восстановления **вне JARVIS**.
4. Подтверди, что ключ сохранён.
5. Создай карточку и нажми «Сохранить карточку».

Минимум мастер-пароля — **6 символов**. Это технический порог, не рекомендация по надёжности: используй длинную уникальную фразу.

### Шифрование

- Карточки и картинки шифруются **AES-GCM, ключ 256 бит**.
- Ключ из мастер-пароля получается через **PBKDF2 / SHA-256, 600 000 итераций**, со случайной солью.
- Данные защищены отдельным случайным ключом; он хранится в зашифрованных обёртках для мастер-пароля и восстановления.
- Ключ восстановления создаётся случайно: 32 байта, отображаемые как 64 шестнадцатеричных символа с разделителями.
- Мастер-пароль не записывается в открытом виде.
- На диске сохраняется отдельный файл `password-vault-v1.json`, а не текст карточек.
- Хранилище блокируется после пяти минут бездействия и при выходе из раздела.

При блокировке несохранённые изменения очищаются. Сохраняй карточку до выхода.

### Если мастер-пароль забыт

Нажми **«Забыли мастер-пароль?»**, введи сохранённый ключ восстановления и задай новый мастер-пароль.

Данные карточек остаются, старый мастер-пароль перестаёт открывать обновлённый файл. Ключ восстановления остаётся действующим.

**Сам ключ восстановления даёт полный доступ.** Не отправляй его в чат, не публикуй и не храни рядом с копией сейфа.

### Если потерян файл

Ключ восстановления не заменяет резервную копию. Чтобы вернуть карточки после потери диска или переустановки системы, нужны:

- копия зашифрованного файла;
- мастер-пароль **или** ключ восстановления.

Если нет ни мастер-пароля, ни ключа, расшифровка не предусмотрена. Если нет файла, восстанавливать нечего.

### Ограничения безопасности

Это первая версия хранилища, **без независимого аудита безопасности**. Она не заявляет защиту от вредоносной программы на компьютере, доступа к памяти разблокированного приложения или записи экрана. Короткий мастер-пароль легче подбирать.

Карточки расшифровываются в памяти для редактирования. Общие настройки, API-ключи и обычные заметки не получают защиту сейфа автоматически. Общий бюджет содержимого сейфа — 24 МБ до шифрования; у карточки с картинками есть отдельный лимит.

Для критически важных секретов оцени риски экспериментальной версии, прежде чем делать её единственным местом хранения.

## Звук и озвучивание

Используются записанные ответы команд и доступные движки озвучивания: локальный XTTS, Silero TTS, резервные варианты Windows SAPI.

- Собственная модель XTTS не включена в репозиторий.
- Silero и XTTS требуют отдельных локальных зависимостей и моделей.
- Первая реплика может быть медленнее из-за загрузки модели.
- Voicemod и VB-CABLE — дополнительные варианты маршрутизации, не обязательное условие для заметок, таймера или обычной диктовки.

Начни с простой схемы: **физический микрофон → JARVIS; звук JARVIS → наушники**. Виртуальные устройства подключай после проверки основного звука. Маршрутизация TTS через Voicemod отличается от обработки твоего микрофона; не замыкай выход обратно на вход.

Если слышишь себя, проверь «Hear myself» в Voicemod, «Прослушивать с данного устройства» в Windows и мониторинг на самой гарнитуре. Диктовка не должна воспроизводить записываемый голос в наушники.

## Что работает без интернета

| Возможность | Условия |
| --- | --- |
| Заметки, календарь, привычки, тренировки, сейф | Локально |
| Таймер и история запросов | Локально; для записи голосовых запросов нужен движок |
| Распознавание речи и диктовка | Локально, если установлена Vosk-модель |
| Чат через Ollama | Локально, если нужная модель уже загружена |
| Перевод и автопунктуация | Локальная Ollama с `qwen3:4b-instruct` |
| Новости, погода и WEB INTEL | Нужен интернет и доступные источники |
| DeepSeek | Нужны интернет и API-ключ |
| Открытие сайтов | Команда может открыть браузер, но сайту нужен интернет |

Первичная загрузка моделей требует сети. «Локально» не означает, что все модели встроены в GitHub.

## Установка и сборка

### Что опубликовано

Последние исходники находятся в ветке **master**. Старый тег `v0.4.0` не перезаписывался и может указывать на более ранний набор функций. Это обновление исходников, не готовый новый установщик.

Проект ориентирован на Windows. Полная переносимость на другие системы не заявлена.

### Требования

Для сборки:

- Rust с Windows MSVC toolchain и C++ Build Tools / Windows SDK.
- Node.js и npm, совместимые с зависимостями проекта.
- Среда WebView2 для интерфейса Tauri.
- Локальные библиотеки аудио и Vosk, необходимые выбранным компонентам.
- Командные ресурсы и модель Vosk для голосового запуска.
- Дополнительные зависимости AutoHotkey для соответствующих сценариев.

Для локальных функций модели установи Ollama. Python, PyTorch и дополнительные модели нужны для выбранного TTS или обучения голоса, а не для всех разделов «Центра».

### Получение исходников

В PowerShell:

```powershell
git clone https://github.com/DIBERLOG/JARVIS_ALTRON_CLEAN.git
cd JARVIS_ALTRON_CLEAN

cd frontend
npm ci
npm run build
cd ..

$env:LIB = (Join-Path (Get-Location) 'lib\windows\amd64') + ';' + $env:LIB
cargo build -p jarvis-app
cargo build -p jarvis-gui
```

Команды выполняются из корня клона. Путь в `LIB` нужен, если линковщик не находит поставляемые Windows-библиотеки, в частности `vosk.lib`.

После сборки рядом с исполняемыми файлами должны быть доступны необходимые DLL и `resources`: команды, звуки и выбранные модели. Наличие исходников само по себе не гарантирует, что все машинно-зависимые ресурсы подготовлены.

### Локальные модели Ollama

```powershell
ollama pull qwen3:8b
ollama pull qwen3:4b-instruct
```

- `qwen3:8b` — вариант для локального чата по умолчанию.
- `qwen3:4b-instruct` — перевод новостей и автопунктуация.

Запусти Ollama перед использованием. Встроенные функции перевода и оформления обращаются к `127.0.0.1:11434`; на Windows предусмотрена попытка запуска установленной Ollama. Производительность зависит от памяти и оборудования.

### Запуск

Из корня репозитория:

```powershell
Start-Process -FilePath '.\target\debug\jarvis-app.exe' -WindowStyle Hidden
Start-Process -FilePath '.\target\debug\jarvis-gui.exe' -WindowStyle Hidden
```

Оба процесса должны использовать одну сборку и совместимые ресурсы. Не держи одновременно несколько старых и новых копий JARVIS.

Для запуска с Voicemod есть [tools/start-jarvis-voicemod.ps1](tools/start-jarvis-voicemod.ps1). Он ищет поддерживаемые пути Voicemod, запускает нужные процессы и ждёт инициализации. Само наличие скрипта не создаёт автозапуск Windows автоматически на новом компьютере.

## Личные данные и резервные копии

Данные разнесены по разным местам:

| Данные | Хранение |
| --- | --- |
| Настройки, данные «Центра», конфигурация чата | Локальная база настроек приложения |
| История запросов, таймер и часть предпочтений интерфейса | Локальное хранилище WebView |
| Черновик диктовки | Память интерфейса до закрытия |
| Карточки паролей | Отдельный зашифрованный `password-vault-v1.json` |
| Модели и ресурсы | Локальные папки проекта / среды моделей |

Файл сейфа находится в папке данных приложения Tauri с идентификатором `com.priler.jarvis`. На Windows проверь папку этого приложения в `%APPDATA%`. Настройки и WebView-данные могут лежать отдельно: одна копия сейфа не сохраняет весь «Центр».

Резервное копирование делай при закрытом приложении. Не включай личные настройки, API-ключи, записи и сейф в публичные коммиты. Очистка истории не удаляет заметки и карточки паролей.

Облачные ответы DeepSeek отправляют запросы сервису. Веб-поиск обращается к внешним источникам, изображения новостей могут загружаться с сайтов издателей. Диктовка, перевод и автопунктуация в указанной локальной конфигурации не требуют отправки текста облачной модели.

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| «Голосовой модуль не подключён» | Запущен ли `jarvis-app.exe`; совпадают ли сборки; нет ли второй копии |
| Волны не двигаются, запись пустая | Устройство диктовки, физический микрофон вместо молчащего виртуального, разрешения Windows |
| Звук есть, текста нет | Язык и доступность Vosk-модели; качество и громкость записи |
| Автопунктуация / перевод недоступны | Работа Ollama и наличие `qwen3:4b-instruct`; повторная обработка после загрузки модели |
| Результат оформления отклонён | Модель изменила слова; исходный текст сохранён |
| Погода или новости не обновляются | Доступ к внешнему сервису, повтор позже; ошибка сервиса не равна проблеме твоего ПК |
| Слышен собственный голос | Voicemod Hear myself, Windows «Прослушивать», аппаратный мониторинг |
| После обновления старый интерфейс | Пересобран ли frontend и затем GUI; закрыта ли старая копия |
| Не скрывается терминал | Есть ли обычное окно консоли у запущенных процессов |
| Не открывается сейф | Мастер-пароль либо ключ восстановления; сохранность зашифрованного файла |
| Ошибка линковщика при сборке | Windows toolchain, путь `LIB`, локальные библиотеки и ресурсы |

Не публикуй лог с API-ключами, текстами секретных записей или ключом восстановления. Для отчёта о проблеме достаточно версии, раздела, последовательности действий и обезличенной ошибки.

## Архитектура и развитие

| Часть | Технологии / расположение |
| --- | --- |
| Голосовой движок | Rust, `crates/jarvis-app` |
| Общая логика, звук и настройки | `crates/jarvis-core` |
| Desktop-команды и окно | Tauri, `crates/jarvis-gui` |
| Интерфейс | Svelte, Vite, TypeScript, `frontend` |
| Распознавание | Vosk |
| Локальная модель | Ollama / Qwen |
| Внешняя модель | DeepSeek API |
| Командные сценарии | Lua / AutoHotkey, `resources/commands` |
| Богатый редактор | Tiptap, очистка HTML через DOMPurify |
| Шифрование сейфа | Web Crypto API |
| Проверки интерфейса и расчётов | `frontend/tests` |

В папке [tools/voice_training](tools/voice_training) есть экспериментальные инструменты подготовки датасета и обучения голоса. Собственная рабочая модель не прилагается. Используй только записи, на которые есть право использования; описание конвейера — в [отдельном README](tools/voice_training/README.md).

### Что пока не обещается

- Синхронизация личных данных между устройствами.
- Готовая Android-версия.
- Автоматическое восстановление старых диалогов.
- Полный перевод страницы новости внутри приложения.
- Медицински безопасное автоматическое назначение рабочих весов.
- Восстановление сейфа без секрета или без файла данных.
- Независимый аудит безопасности сейфа.
- Гарантированная работа каждого внешнего источника.
- Новый готовый установщик со всеми моделями.

Отдельный раздел «Вопросы JARVIS» убран из меню. Его прежние сценарии не следует считать реализованной автоматической системой опросов.

Приоритеты дальнейшего развития: устойчивость распознавания и внешних сервисов, резервные копии, удобное развёртывание, тестирование и независимая проверка защиты секретных данных.
