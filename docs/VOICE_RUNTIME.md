# Быстрая озвучка JARVIS

Выбранный локальный голос: XTTS после доработки, сессия `20261004-131203`.
Профиль: `jarvis_ru_012.wav`, скорость 1.0, seed 28, temperature 0.42,
top_p 0.72. Дополнительные эквалайзеры и изменение высоты голоса отключены.
Предыдущие модели и записи не удаляются.

## Как устроен ответ

- Записанные ответы команд остаются MP3: их не нужно синтезировать.
- XTTS загружается в фоновом процессе один раз и сохраняет conditioning.
- Подготовка модели не блокирует очередь готовых MP3.
- Повторяющиеся реплики берутся из локального WAV-кэша
  `%LOCALAPPDATA%/JarvisVoiceStudio/speech-cache`.
- Ответы Ollama и DeepSeek принимаются потоково, но передаются на озвучку целиком.
  Разбиение озвучки временно отключено; исправлена передача русского текста
  в UTF-8 между Rust и Python на Windows.
- Отмена озвучки сбрасывает текущую очередь; отменённый поток не добавляет новые фразы.
  После принудительной остановки голосовой процесс загружается снова при следующем ответе.
- Внутри вопроса допускается пауза около 2.2 секунды; завершённые части
  распознавания объединяются до отправки вопроса.

## Ограничения

Первый прогрев требует времени. Измеренный локальный no-play smoke-test:
прогрев 17.813 с, первая короткая фраза 4.937 с, повтор из кэша менее 0.001 с.
Это не полная задержка разговора: сеть, языковая модель и воспроизведение сюда не входят.
На GPU с 8 ГБ одновременные XTTS и крупная локальная языковая модель могут
не поместиться. Провайдер DeepSeek не меняется автоматически на Ollama.
Для Ollama запросы отключают thinking, используют контекст 2048 и keep_alive 15m.
Уже установленная qwen3:4b-instruct — меньший локальный вариант; выбор модели
остаётся в настройках пользователя.

## Проверки

`tools/voice_training/test_resident_xtts.py` проверяет постоянный процесс без
проигрывания аудио и повторный запрос из кэша. Rust-тесты проверяют границы
предложений и оба формата потокового ответа на локальном тестовом сервере.
Основная модель находится вне поставляемого EXE: приложение использует
`resources/tts/trained-checkpoint.txt` и локальные файлы указанной сессии.
