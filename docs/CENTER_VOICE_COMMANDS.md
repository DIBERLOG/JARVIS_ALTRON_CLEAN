# Голосовой Центр JARVIS

Команды выполняются голосовым модулем с открытым окном приложения, в том числе внутри разговорного режима. После уточняющего вопроса можно отвечать без повторного «Джарвис». Контекст уточнения действует 90 секунд; «отмена» прекращает действие.

## Поддерживаемые действия

- «Открой личный центр / новости / календарь / заметки / привычки / тренировки / зарядку / мои параметры / статистику / хранилище».
- «Обнови новости», «Обнови ленту», «Обновить ленту». Работает из другой вкладки: сначала открывает новости, ждёт подключения раздела, затем обновляет данные.
- «Переведи новость номер два» или «Переведи новость» → вопрос о номере. Номер соответствует текущей ленте. Изменившаяся лента не допускает перевода случайной публикации.
- «Запусти таймер работа / учёба / перерыв / игры / тренировка / сон», а также названия собственных пресетов.
- «Запусти таймер на десять минут». «Установи таймер» спрашивает длительность. «Запусти пресет таймера» спрашивает название или номер; принимаются названия собственных пресетов.
- «Пауза таймера», «Продолжи таймер», «Сбрось таймер».
- «Создай заметку / новый чек-лист» → название → содержание. Для чек-листа разделяйте пункты словами «следующий пункт».
- «Дополни заметку» → номер → текст. Существующее оформление и изображения не удаляются.
- «Отметь привычку» → номер. Для количественной привычки добавляется единица, а не отмечается сразу вся цель.
- «Добавь напоминание» → содержание → время → подтверждение. Время: «через десять минут», «завтра в 18:30» или «04.10 в 18:30»; свободный разбор любой даты пока не поддерживается.
- «Добавь день рождения» → имя → дата `12.04`.
- «Запиши мой вес» → вес в килограммах. На одну дату сохраняется одно измерение.
- «Расписание на сегодня» → активные напоминания.
- «Останови озвучку».

## Таймер

При включённом звуке проигрывает ваши записи за пять минут, за минуту и по завершении. Повторный опрос и пауза не повторяют уже пройденный порог. Если приложение было приостановлено, озвучивается только актуальный порог. Предупреждения не перебивают другую озвучку или уточнение. Для работы нужен запущенный голосовой модуль; таймер хранится локально, но закрытое приложение не выдаёт уведомления.

Для собственных записей предупреждений:

- «До конца таймера осталось пять минут, сэр.»
- «До конца таймера осталась одна минута, сэр.»

## Погода

Неделя — обычный прогноз. 30 и 60 дней — сезонная модельная оценка ECMWF, среднее ансамбля, без выдуманных значков дождя и рекомендаций по одежде. Длинный период не является точным прогнозом по дням. Реальные данные доступны страницами по семь дней. Источник: https://open-meteo.com/en/docs/seasonal-forecast-api

## Аудиофайлы

К предыдущим 34 записям добавлены 48 новых: вопросы, ошибки, подтверждения и предупреждения таймера. Для дубля отметки привычки выбрана поздняя запись 16:51. Новые ответы проигрывают MP3; изменяемые номера, названия и даты показываются текстом на экране. Некоторые записи зарезервированы для следующих действий: запуск/завершение диктовки, генерация тренировки и блокировка хранилища. Открытие соответствующего раздела не означает выполнение этих действий.

## Список в интерфейсе

К 33 прежним командам добавлены 32 реализованных действия Центра: всего 65. Счётчик и список используют один источник; в режиме категорий доступен «Личный центр». Каталог находится в `crates/jarvis-core/src/commands/center.rs`; точные фразы каталога также проверяются голосовым обработчиком до обращения к модели.

## Идеи следующего этапа

- «Утренний брифинг»: погода, планы, выбранные новости и привычки.
- «Рабочая сессия»: рабочий таймер, нужные приложения, напоминание о перерыве.
- «Вечерний итог»: выполненные привычки, тренировка и планы на завтра.
- «Запомни из буфера»: новая заметка из скопированного текста после подтверждения.
- «Режим тишины на час»: временное отключение голоса с автоматическим возвратом.
- «Сохрани резервную копию»: локальный экспорт данных без раскрытия паролей.
# Свободные варианты формулировок

Можно добавлять «пожалуйста», «можешь», говорить глаголы в начальной форме.
Номер, время и содержание заметки сохраняются; отрицание не превращается в команду.

| Действие | Примеры фраз |
|---|---|
| Начать разговор | Давай поговорим; давай поболтаем; хочу поговорить; включи разговорный режим |
| Завершить разговор | Хватит разговаривать; заверши разговор; вернись в режим команд; отмени разговор |
| Открыть раздел | Открой заметки; можешь открыть заметки; перейди в заметки |
| Таймер | Поставь таймер на десять минут; включи таймер учёба; можешь поставить таймер |
| Новостная лента | Обновить ленту; пожалуйста обнови новости; освежи ленту |
| Перевод новости | Можешь перевести вторую новость; переведи новость пожалуйста |
| Новая заметка | Создать заметку; сделай заметку; новая заметка |
| Напоминание | Поставь напоминание; можешь создать напоминание |
| Подтверждение уточнения | Да; ага; угу; давай; хорошо; окей; согласен; всё верно; да сохрани |
| Отмена уточнения | Отмена; отмени; нет; не надо; не нужно; не сохраняй; передумал |
| Интернет в разговоре | Найди в интернете последние новости нейросетей; поищи официальный сайт Rust; проверь в сети |

Веб-поиск выполняет приложение и передаёт найденные ссылки и выдержки DeepSeek.
Сам API модели не становится браузером. При сбое поиска JARVIS должен сообщить об
этом, а не выдавать знания модели за проверенные свежие сведения.
